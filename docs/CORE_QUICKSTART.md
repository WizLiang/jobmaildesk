# Windows 定制版快速开始

## 打开程序

使用经过验证的候选便携包，解压完整文件夹后运行 `JobMailDesk.exe`。普通用户无需安装 Python。`JobMailDesk-cli.exe` 是命令行入口，`_internal` 是运行依赖，不能只保留一个 EXE。

首次打开先选择数据存放位置，程序在所选位置创建 `JobMailDeskData`，再进入邮箱设置。设置中可以更换数据位置并迁移；之后升级程序会记住该位置。旧版默认目录只用于兼容迁移。

## 设置邮箱

1. 选择邮箱服务商或自定义 IMAP，检查主机、端口和 SSL/TLS。
2. 填写完整邮箱地址和客户端授权码，不填写日常登录密码。
3. 点击“测试只读邮箱连接”，通过后保存并应用。
4. 不使用 Obsidian 时保持同步关闭，本地功能仍然可用。

授权码由系统凭据库保存。IMAP 以只读方式读取，不删除、移动邮件或主动改变未读状态。

设置会显示当前扫描账号。更换邮箱需填写新账号的授权码；只有保持同一账号时才可留空。扫描进行中需等待完成后保存设置。

## 扫描与确认

每个邮箱及文件夹首次扫描最近 30 天的已读和未读邮件，日常默认回看 3 天并按设定间隔扫描；停用后自动补齐未扫描时间段。读取或识别部分失败时保留缺口，下次继续重试。界面显示连接、读取、识别和保存阶段，以及当前阶段的处理数量；失败数量会保留在主界面和设置中。

默认过滤宣讲会、岗位推荐和邀投简历。如需关注线下活动，可开启“保留有明确时间和线下地点的宣讲会”。候选邮件先进入待处理，确认归属后才进入正式进展、待办或日历。

公司或岗位待确认时可展开查看原因和识别依据，再选择已有申请或创建新申请。无法确定的内容不会强行归属。

遗漏历史邮件时，在待处理或设置中选择单次补扫 7／30／90 天；补扫不修改日常扫描范围，人工确认、忽略和删除状态保持优先。误忽略的待归属邮件可从“已忽略邮件”中恢复，恢复后仍需确认归属。

“待处理 → 自动过滤”显示被过滤的招聘宣传摘要与原因，可移回待处理后确认归属。这里不保存原邮件正文。升级后下一次扫描会重查最近 30 天；更早或升级前没有摘要的邮件可通过历史补扫重新检查。恢复后的记录不会再次被自动过滤。

## 台账与笔记软件

“导入台账修改”读取设置中指定的本地 Markdown 台账，将手工修改更新到卡片，再刷新输出。它不扫描邮箱。只用卡片操作时可以不使用这一入口。

Obsidian 同步是可选功能；当前没有 Notion 或语雀自动同步接口。台账格式见 [台账模板](PROGRESS_LEDGER_TEMPLATE.md)。

## 升级和清除数据

窗口右上角关闭会隐藏到托盘。手动升级前从托盘菜单退出，再运行新版完整程序文件夹；无需每次重新安装，原数据位置会保留。

0.7.0rc2 起可在“设置 → 程序更新”检查、下载并校验新版，再确认重启更新。首次使用可选开启每天检查，下载仍需点击。具体范围与失败回退见 [更新说明](UPDATES.md)。0.7.0rc1 及更早版本需先手动安装一次新版。

0.7.0rc3 起，该设置页同时显示当前版本，反馈问题时可附上。选择“试用版与正式版”才能接收 rc 测试版；“仅正式版”会跳过它们。

设置中的“清除个人信息”需输入“清除”并确认，清理应用管理的数据与凭据。服务器邮件、外部 Obsidian 文档、手动备份和已导入其他日历的事件不在清除范围内。详见 [隐私清除说明](PRIVACY_RESET.md)。

当前 Windows 包属于候选构建；历史 macOS 发布记录不代表本次定制版已通过 macOS 验收。
