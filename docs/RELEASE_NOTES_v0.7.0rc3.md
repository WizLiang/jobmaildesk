# Windows 维护更新：版本与更新可靠性

- “设置 → 程序更新”显示当前运行版本，便于确认升级和反馈问题。
- 修复检查失败后仍冷却 24 小时、重启后新版提示消失的问题；自动检查不会打断已下载待安装的更新。
- 再次下载时清理更新器生成的过期 ZIP 缓存，失败时保留已有可用更新包。程序备份与用户文件不自动删除。
- 统一源码、锁文件、Windows EXE 和包名版本检查，防止旧程序误打包为新版；完善 Windows 维护手册、发布清单和脱敏反馈模板。

已安装 0.7.0rc2：进入“设置 → 程序更新”，选择“试用版与正式版”，检查、下载后确认重启。0.7.0rc1 或更早版本需手动下载 ZIP，退出托盘旧程序后完整解压运行，不能只复制 EXE。

数据存放位置、任务、邮箱凭据和可选 Markdown 同步配置沿用原设置。此版本仅发布 Windows x64 ZIP 和 SHA-256；macOS 不作为当前支持目标。

仍为未签名预发布，自动化与空数据包自检不能替代长期真实使用和所有原生退出重启场景。程序目录旁的旧版本备份可在确认新版正常后自行清理。反馈时请附版本和复现步骤，勿上传授权码、邮件原文或数据目录。
