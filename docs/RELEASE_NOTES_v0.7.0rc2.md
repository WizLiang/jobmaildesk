# Windows 试用版：GitHub 更新

设置新增“程序更新”：检查本仓库新版、下载并校验 ZIP，确认后重启更新。
可选择接收试用版与正式版，或仅正式版；每日检查默认关闭，可自行开启。
更新保留原数据位置和系统凭据，主界面不常驻显示版本号。

首次从 0.7.0rc1 或更早版本升级，需手动下载并解压完整程序文件夹一次。
之后可在程序内获取后续 Release，代码推送本身不会触发客户端安装。

程序只访问本仓库公开发布，不需要 GitHub 登录或 SSH 密钥，不发送邮箱和求职数据。
安装前校验 SHA-256、ZIP 路径和包内 CLI 启动；替换失败尝试恢复旧目录。
旧程序备份保留在程序目录旁，正常使用后可自行清理。
若程序目录与数据目录重叠、含额外文件夹或权限不足，请按提示手动更新。

这是 Windows x64 未签名预发布，不包含 macOS。请先保存编辑内容再重启更新。
自动化测试和包内自检不能替代所有真实网络、断电及系统安全软件场景的试用反馈。
