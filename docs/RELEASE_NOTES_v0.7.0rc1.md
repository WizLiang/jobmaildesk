# JobMailDesk Windows 首个试用发布

适用：Windows 10/11 x64。此版本为未签名预发布，用于试用反馈。

包含个人信息清除、自选数据目录、招聘宣传过滤与线下宣讲会选项、扫描进度、
公司与岗位识别增强、确认原因、7／30／90 天历史补扫、已忽略邮件恢复。

下载 win-x64.zip 及同名 .sha256，核对后解压完整文件夹，运行 JobMailDesk/JobMailDesk.exe。
升级前从托盘退出旧版，沿用已有数据位置。不要只复制单个 EXE。
首次使用自行设置邮箱客户端授权码；包中不含用户数据或账号。

此版本尚不具备应用内更新功能；后续支持更新的版本需要先手动安装一次。
本次不发布 macOS 包，也不承诺 macOS 支持。

验证：Windows 本地完整测试 540 通过、1 跳过，云端 Windows 测试和打包通过。
标签流程再次执行测试、秘密扫描、构建、空数据自检和 ZIP 校验。
真实邮箱与原生交互的长期试用仍需反馈，不等同于已完成正式发布验收。
