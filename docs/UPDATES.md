# Windows GitHub 更新

从 0.7.0rc2 起，在“设置 → 程序更新”点击检查更新。默认选择“试用版与正式版”；选择“仅正式版”会跳过所有 prerelease。比较实际版本号，不按发布日期降级安装。

每日检查默认关闭，用户勾选并保存后才启用。检查仅提示，下载与重启都需要主动点击。检查使用公开 GitHub API，不需要登录、SSH key、Token 或邮箱信息。

更新只接受 WizLiang/jobmaildesk 仓库发布的 Windows x64 ZIP 及同名 .sha256。程序检查 HTTPS 地址、文件名和 SHA-256，拒绝异常解压路径、不完整程序和不受信任的跳转。发布说明作为纯文本显示。

下载缓存存放在所选数据目录的 updates 下。安装前再次校验缓存，并在程序目录旁准备新文件夹；旧进程退出后替换完整程序目录并重启。原程序中的额外普通文件保留；如包含额外文件夹、链接或与数据目录重叠，则拒绝自动替换并提示手动更新。

替换失败会尝试恢复原目录。旧程序备份位于原程序目录旁，名称以 .jobmaildesk-backup- 开头。确认新版正常后可自行删除备份；发生断电等中断时可退出所有程序后，从备份目录恢复旧程序。程序数据与系统凭据不随版本替换。

权限不足、网络受限或不适合自动替换时，点击“打开发布页”，从托盘退出旧程序，再解压完整新版程序文件夹。不要只复制单个 EXE；它依赖 _internal。0.7.0rc1 及更早版本需要手动安装一次支持更新的版本。

此流程尚未提供独立签名验证，GitHub 仓库发布权限必须妥善管理。macOS 暂不支持此更新流程。
