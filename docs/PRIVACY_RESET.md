# 清除个人信息（Windows）

设置 → 个人信息 → 清除个人信息，输入“清除”并确认。程序退出后清理，再自动打开首次设置。

清除使用当前选择的数据根目录，支持非 C 盘位置；保留所选位置本身，下次使用不必再次选择。迁移未完成时不允许同时清除。

清除范围：

- Windows 凭据库里的当前邮箱、旧版 QQ 邮箱凭据和私人链接加密密钥。
- 当前数据目录内的待办、申请链、待处理邮件信息、历史简报、词典与学习密钥。
- 数据库及 WAL/SHM/journal、私人链接、研究队列、配置、缓存、事务恢复副本、日志和 WebView2 浏览器数据。
- 当前数据目录内的日历导出、配置所指向的本地输出文件，以及应用原子写入留下的临时文件。

不会删除邮箱服务器的邮件。外部 Obsidian 文档、目录外的研究队列、手动备份（包括安装导入生成的 `.bak-*`）、已导入其他日历软件的事件需单独清理。自定义数据目录中的非应用文件保留。此功能为逻辑删除，不承诺磁盘取证级擦除。

不创建隐私数据备份。`\.privacy-reset.json` 仅保存流程版本、旧进程 ID 和本地文件名；新进程必须等待旧进程退出，取得单实例和数据锁后才删除。完成前不允许常规启动、事务恢复或邮箱扫描。凭据、权限、文件占用等问题会显示失败提示，清除请求保留，重新启动会重试；不会把部分清除报告为成功。

验收用虚构记录和隔离凭据后端测试，不读取或删除测试者真实邮箱凭据。Windows 进程等待及目录联接防护另外做实测。
