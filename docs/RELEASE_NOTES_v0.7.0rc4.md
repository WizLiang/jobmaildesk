# Windows 扫描可靠性与过滤复查

- 设置显示当前扫描账号；更换邮箱需填写新授权码，不再错误复用旧账号凭据。
- 切换后作废排队的旧扫描；保存失败回退原配置。设置已保存但调度器未恢复时，明确提示暂停扫描并要求退出重启。
- 每个邮箱及文件夹首扫 30 天；停用后自动补齐扫描缺口。首次失败保留原起点，部分失败或取消不会提前记为已覆盖。
- 部分扫描失败持续显示读取失败、识别失败数量，刷新和重启后仍可查看。
- 待处理新增“自动过滤”：查看脱敏宣传摘要和原因，移回待处理后人工确认。人工恢复、忽略、确认和删除状态保持优先。

升级后会重新检查最近 30 天并补齐过滤摘要，可能比日常扫描耗时更长；更早邮件可单次补扫 7／30／90 天。重复扫描不会重复建卡，邮箱邮件保持只读。

0.7.0rc2 或更高版本可在“设置 → 程序更新”选择“试用版与正式版”，检查、下载后确认重启。更早版本需退出托盘旧程序，再完整解压新版 ZIP 运行。数据目录、任务和系统凭据沿用原设置。

仍为未签名 Windows x64 预发布，仅提供 ZIP 和 SHA-256。自动化与合成界面检查不能代替真实邮箱、实际 GUI 更新重启和长期试运行；本轮未完成这些人工验收。反馈时请提供版本和复现步骤，勿上传授权码、原邮件或完整数据目录。

本候选从通过验收的 `agent/scan-reliability` 功能分支发布，源码合并主线另行通过 Pull Request 完成。
