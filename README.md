# JobMailDesk · 求职纸片

这是 JobMailDesk Windows 定制版的源码仓库，用于整理招聘邮件、求职进展和本地待办。

首次源码导入正在 [agent/windows-import](https://github.com/WizLiang/jobmaildesk/tree/agent/windows-import) 分支进行，通过 Pull Request 审核后进入 main。当前尚未发布正式安装包。

本项目基于 [Chpeeeeea/job-mail-desk](https://github.com/Chpeeeeea/job-mail-desk) 二次开发，保留原作者版权与 [MIT 许可](LICENSE.md)。本仓库不包含用户运行数据或邮箱授权码。
